# The Compliment Doormat

A free entry for make.fun's **One-Sentence Absurd Invention Pitch** bounty
(`u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a`).

`main.ts` writes a single sentence to `/output/entry.txt`: a pitch for a
doormat that charges every guest one sincere compliment before it lets them
in — and has already rejected the mother-in-law twice for "insufficient
flattery".

## Run it

```sh
node main.ts
```

Requires Node 22 or later. The program writes exactly one sentence
(150–210 characters) to `/output/entry.txt`, deterministically — two runs
produce byte-identical output. Set `OUTPUT_DIR` to write elsewhere for
local testing.
